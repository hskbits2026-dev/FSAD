This Project enables Customer to shop online i.e place orders and search for the products under
various categories. This Project also enables admin to monitor the online sales and also to manage
the products available to the customers. He is also enabled to view reports about the online sales
happened for analysis.

Requirements:

    1) Logins are made available separately for the admin and the Customer.

    2) Registered customers should be able to view the products (All details - Product Id, Name,
       Description, Price, QOH) category wise (Electronics, Electrical, Furniture, Cosmetics,
       Toys & Books) and product wise.

    3) Customers should be able to add the products to a shopping cart and also remove it from
       the cart.

    4) Customers should be able to order the goods that are added to the cart and also delete
       the orders.

    5) Customers should be able to send feedback.

    6) Admin should be able to login and update the products under various categories like
       Electronics, Electrical, Furniture, Cosmetics, Toys & Books. Details should include
       Product Id, Name, Description, Price, QOH (add/delete/modify).

    7) Admin should be able to view the sales happened over a Week, Month, Qtr & Year -
       Product wise as well as Category wise sales.
       (Sales Details are understood to be already updated using the previous module)

    8) Reports should be made available for the sales of the products and also regarding the
       Customer Feedback.

    9) Administrator should be able to analyse based on the sales the fast moving and slow
       moving products.

Modules:

    1) Login/Registration Module
    2) Products Search Module
    3) Ordering Module
    4) Feedback Module
    5) Products Updation Module
    6) Sales Analysis Module
    7) Reports Module

Technology Stack:

    Option A:
        - Spring Boot / Spring MVC
        - MySQL
        - ReactJS with Spring Data JPA / Hibernate

    Option B:
        - Spring Boot / Spring MVC + ORM + JSP / Thymeleaf
        OR
        - Java + Hibernate CLI
